StreamClip - Privacy Policy

StreamClip is a personal desktop tool used by a single individual. It runs locally on the owner's computer.

  1. Data we access. After the owner authorizes the app with TikTok Login Kit, the tool receives an access token for the owner's own TikTok account.
  2. How data is used. The token is used only to upload videos chosen by the owner to the owner's own TikTok account through the Content Posting API.
  3. Storage. The token is stored only on the owner's computer. It is not sent to any server operated by us, and no personal data is collected, sold or shared with third parties.
  4. Revoking access. The owner can revoke access at any time from TikTok's app settings or by deleting the local configuration file.
